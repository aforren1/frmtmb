# Likelihood-ratio tests between nested frmtmb fits

Likelihood-ratio tests between nested frmtmb fits

## Usage

``` r
# S3 method for class 'frmtmb_fit'
anova(object, ...)
```

## Arguments

- object:

  A `frmtmb_fit`.

- ...:

  Further `frmtmb_fit` objects, nested with `object`.

## Value

An `anova` table.
