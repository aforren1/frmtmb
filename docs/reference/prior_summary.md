# Priors used in a fit

Priors used in a fit

## Usage

``` r
prior_summary(object, ...)

# S3 method for class 'frmtmb_fit'
prior_summary(object, ...)
```

## Arguments

- object:

  A `frmtmb_fit`.

- ...:

  Unused.

## Value

The `frmtmb_priorlist` the fit was penalized with, or (invisibly) `NULL`
for a plain maximum-likelihood fit.
