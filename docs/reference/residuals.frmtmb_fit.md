# Residuals from a frmtmb fit

Residuals from a frmtmb fit

## Usage

``` r
# S3 method for class 'frmtmb_fit'
residuals(object, type = c("response", "pearson"), ...)
```

## Arguments

- object:

  A `frmtmb_fit`.

- type:

  `"response"` or `"pearson"`.

- ...:

  Unused.

## Value

A numeric vector.
