# Extract random-effect covariance matrices

Extract random-effect covariance matrices

## Usage

``` r
VarCorr(x, ...)

# S3 method for class 'frmtmb_fit'
VarCorr(x, ...)
```

## Arguments

- x:

  A `frmtmb_fit`.

- ...:

  Unused.

## Value

A named list of covariance matrices, one per random-effect term.
