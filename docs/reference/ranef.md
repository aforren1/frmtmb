# Extract random-effect modes

Extract random-effect modes

## Usage

``` r
ranef(object, ...)

# S3 method for class 'frmtmb_fit'
ranef(object, ...)
```

## Arguments

- object:

  A `frmtmb_fit`.

- ...:

  Unused.

## Value

A named list of levels-by-coefficients matrices, one per random-effect
term.
