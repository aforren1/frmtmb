into frmtmb 0.74.0. It is the first round under the core boundary rule
(`dev/core-boundary.md`): every lane moved a feature between packages.

left. Each lane's `dev/<lane>-findings.md` has its validation, numbers

## How the release tree was built

The lanes were combined in `../frmtmb-wt-release` (branch `wt-release`
at `19b162b9`), in the brief's order: splitsurv, mvnlatent, spatial.
Every lane is on `19b162b9`, so the base of every merge is the HEAD
blob. Nothing was committed and no git write was made: blobs are read
with `git show`, and `git merge-file` works on files, not on the index.

- `dev/rel074-merge.sh` (from `dev/rel073-merge.sh`) merges in one
  rerunnable pass: it restores each file any lane changed or deleted to
  its HEAD blob, removes the untracked lane files an earlier run copied
  (`dev/rel074-log/copied-<lane>.lst`), merges the lanes in order with
  `git merge-file` (line endings normalized to LF), applies the lanes'
  deletions, copies the lanes' untracked files again (stored as LF),
  regenerates `R/links-brms.R` with the merged generator
  (`dev/famlink-gen-links.R`), then runs the consolidation's edits
  (`dev/rel074-resolve.R`) and the NEWS merge
  (`dev/rel074-news-merge.R`), and stops if a conflict marker is left.
  New in this round: a deletion is applied when the file is still the
  base blob, and a deletion of a file another lane changed (or the
  reverse) is a conflict; none occurred. `man/*.Rd`, `NAMESPACE`,
  frmtmb.sample's generated `helper-brms-suite.R` and `R/links-brms.R`
  are left out of the textual merge; roxygen and the generator write
  them.
- Files changed or deleted (`dev/rel074-log/merge-work/<lane>.status`):
  splitsurv 100 (44 deletions: frmtmb.spline's 41 files, its check
  workflow, core's `man/cox_baseline.Rd` and `test-cox-chart.R`),
  mvnlatent 47 (2 deletions), spatial 66 (1 deletion); 173 in all, 142
  without the generated ones (`dev/rel074-log/merge-2.txt`).
- Untracked lane files copied (`merge-2.txt`): splitsurv 91, mvnlatent
  27, spatial 66; 1 clash, `R/extension-home.R` (resolution 1). Among
  them every `dev/<lane>-*` script and findings file,
  `dev/reviews/2026-10-23-<lane>.md`, the two new packages, the new
  core files and the lanes' new tests. Not copied, as the brief says:
  the reviewers' `dev/review-*` scripts (18, 10 and 22), each lane's
  copy of `dev/core-boundary.md`, generated Rd files, Stan caches, the
  brms suite, logs and check trees (gitignored).
- The generator's `R/links-brms.R` equals lane splitsurv's file byte
  for byte, line endings aside: 50 families, 274 (family, link) pairs,
  no `cox` (`merge-2.txt`).
- The release library is `C:/Users/adf44/source/r/rellib-r12`, new
  (`dev/rel074-install.sh <lib>`: roxygen of core, install, roxygen of
  each extension against it, install in dependency order, drmTMB 0.7.0
