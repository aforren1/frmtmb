== 1. where brms's rhat comes from ==
brms's rhat generic environment:  posterior 
  rhat.brmsfit in posterior's table: TRUE
  rhat.brmsfit in bayesplot's table: FALSE
brms's rhat.brmsfit body:
{
    contains_draws(x)
    draws <- as_draws_array(x, variable = pars, ...)
    tmp <- posterior::summarise_draws(draws, rhat = posterior::rhat)
    rhat <- tmp$rhat
    names(rhat) <- tmp$variable
    rhat
}
