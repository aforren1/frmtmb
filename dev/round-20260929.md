## How the release tree was built

There was no git identity on the new machine, so no commit could be
made during consolidation. The seven lanes were combined in a separate
worktree, `../frmtmb-wt-release`, by applying each lane's uncommitted
diff with `git apply --3way`, generated files (`man/`, `NAMESPACE`)
excluded and regenerated by `roxygen2::roxygenise()` afterwards. The
regenerated `man/` pages were exactly the 14 the lanes had changed.

Conflicts, all resolved by hand:

- `dev/test-backlog.md`, `NEWS.md` and `.gitignore`: sections appended
  at the same place by several lanes. Both sides kept.
- `R/influence.R`: lane thresrefit's failed-refit counter and lane
  csfactor's lost-coefficient warning, two additions to the same refit
  loop. Both kept, in that order.
- `R/bootstrap.R`: lane resmooth reworded a roxygen paragraph that lane
  thresrefit appended a section after. Both kept.

`R/frame.R`, which lanes csfactor and thresrefit both edited, applied
without conflict.

## How the tier runs were lost and redone

The first launch of the four tiers ran with a log watcher, `tail -F`,
on their logs. On Windows that locks a log a PowerShell driver appends
to, and the stopped watcher's `tail` kept running, as did nine others
from the session's earlier watchers. The suite and gated tiers were
stopped at their drivers, their in-flight R processes allowed to finish
their files, and relaunched; the relaunched gated tier still logged
nothing and printed "GATED ran 39 of 39". Only after every `tail.exe`
was killed did a run log what it ran. Every number above is from a run
whose log holds one `RESULT` line per declared file.

## After the push

The first run of `pkgdown.yaml` on GitHub failed at the frmtmb.eam
site: rendering `lba.Rd`, pkgdown loaded `rtdists`, whose dependency
`gsl` needs the system `libgsl`, which the runner lacked because the
extensions' dependencies are installed with `install.packages()` and
not pak. Pages was still in legacy mode, so nothing was served wrong.
The same gap had been silent on `check-frmtmb-eam.yaml`: all six
`rtdists` comparisons in `test-lba.R` skipped there with "{rtdists}
cannot be loaded", on every run. Both workflows now install
`libgsl-dev`; the Windows runs never showed it, because the gsl binary
there bundles its own library.
