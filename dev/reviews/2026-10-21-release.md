Reviewer: adversarial release review, 2026-10-21. Release tree
`frmtmb-wt-release` (branch wt-release at 4854e425, the four-lane merge
uncommitted), installed in `wt-release-lib` and `rellib-r11`. Base
build `rellib-r10` (0.72.0). Lane worktrees `frmtmb-wt-<lane>` (read
only). No library was built: every run used `rellib-r11`,
`wt-release-lib` or `rellib-r10`, with brms 2.23.0 from the user

## Verdict: SHIP AFTER FIXES

No defect in the merge and no code defect that blocks the release. The
merge reproduces from scratch, every file that several lanes changed
holds exactly each lane's lines plus the recorded resolve edits, and
the record's numbers regenerate: fuzz 37/21/0/5, the SE battery, the
vignette columns, 15 flipped ported-suite rows. Of the cross-lane
probes, all compose but one: cdfs makes 8 more families censorable,
and fuzzfix's two refusals do not run under `cens()`. So `cens()` with
no censored row now bypasses both refusals (finding 1). The fixes are a
NEWS sentence, a backlog entry and record corrections. A code fix for
finding 1 is cheap, but it is optional for this release.

1. **MEDIUM (cross-lane). `cens()` bypasses the asym_laplace and
   weights refusals, on families that cdfs made censorable.**
   `check_weights_unbounded()` returns early on `cens()`
   (`R/weights-unbounded.R:73`). That was a fail-open choice when few
   spike-table families had a CDF. Lane cdfs adds `cens()` for
   student, skew_normal, exgaussian, shifted_lognormal, asym_laplace,
   von_mises, Gamma and Beta. So adding a censoring column in which no
   row is censored turns each refusal off:
   - `dev/rel073-rev-alap.R`, `dev/rel073-rev-log/alap-r1{0,1}.txt`
     (seed 7, 80 rows, no weights): `asym_laplace` `y ~ x + (1 | obs)`
     is refused on 0.73.0. `y | cens(cn) ~ x + (1 | obs)` with every
     `cn` "none" gives logLik 762.9200, sigma 1.6e-05, conv 1. On
     0.72.0 that model was refused, because asym_laplace had no CDF, so
     this runaway is new. It is reachable only on the merged build.
   - `dev/rel073-rev-probe.R wcens`, `probe-wcens-r11.txt` (weights
     1.5, `(1 | obs)`): Gamma with `cens(cnone)` gives logLik 51116161
     and log shape 45.71. gaussian gives 1291.66, student 653.76. The
     same models without `cens()`, or with `trunc()`, are refused.
     With 20% of the rows right censored, gaussian still runs away
     (331.30).
   - Each of these fits warns (false convergence, a large gradient), so
     none is silent.
   - The weights bullet in NEWS says "The check does not run with
     `se()`, `cens()`, ...". The asym_laplace bullet says "refused ...
     at any weights" and does not name the exception.
   - Not a cross-lane case, but the same check:
     `zero_inflated_asym_laplace()` with `(1 | obs)` runs away on both
     builds (logLik 280.0635, sigma 0.00132), because it is not in
     `unbounded_spike_dpar`.

   Fix for this release: add to the asym_laplace bullet "The check does
   not run with `cens()`, as the weights check does not". File both
   items in "Filed at the 0.73.0 release". The code fix (optional): a
   censored row's probability is at most 1, so the spike argument holds
   on the uncensored rows. Run the check on the rows whose censoring
   code is "none", and do not skip it.

### 3. Is the 1/2 allowance safe? Yes, in the direction that matters

The allowance can only miss a runaway. It cannot refuse a bounded
Laplace objective. Fix tau, the fixed effects and every other
parameter, and send the spike scale `s` to 0.

- **An uncensored row** with its own effect adds `(w - 1) log(1/s)` (or
  `w log(1/s)` for asym_laplace under Laplace), plus O(1). This is the
  existing argument.
- **A censored row** adds `max_u [w log P(u) + log N(u; 0, tau)] - (1/2)
  log H`.
  - The first term is bounded above by `log N(0; 0, tau)`. It is
    bounded below, because `u` can sit a fixed distance inside the
    censored region, where `log P` goes to 0.
  - At the inner mode, `w d(log P)/du = u / tau^2 = O(1)`. Write `z`
    for the position in units of `s`, so that
    `d(log P)/du = g(z) / s` and `-d^2(log P)/du^2 = g'(z) / s^2`.
    Then `g(z) = O(s)` there, and
    `H = 1/tau^2 + w g'(z) / s^2 = O((1/s) g'(z)/g(z))`.
  - For the tails of the table's families, `g'/g` grows at most like
    a power of `z` that is below 1, at the `z` where `g(z) = s`. A
    gaussian-like tail gives `z ~ sqrt(log(1/s))`. An exponential
    tail (asym_laplace, exgaussian, the Weibull and GEV types) gives a
    constant. A Student tail gives about `1/z`. Beta and von Mises
    become gaussian as the precision grows, and their supports widen
    to infinity in units of `s`.
  - So `-(1/2) log H >= (1/2) log s - O(log log(1/s))`.
  - When the prior mean already lies inside the censored region, the
    mode stays at O(1) and `H` stays bounded, so the cost is 0.
- **So** each censored row costs at most half a power, plus a term
  that grows more slowly than any power. The Laplace objective is at
  least `(E_unc - n_cens/2) log(1/s) - O(n_cens log log(1/s)) - C`,
  which grows without bound whenever the check refuses
  (`E_unc - n_cens/2 > 0`).
- **What could break it:** a family whose standardized tail is lighter
  than gaussian at the relevant `z`, for example one with a fixed
  compact support. No family in the table has one.
- **The measured cost** is well below 1/2 per censored row. The profile
  slope at an excess of 7.5 is about 5, so the cost is about 0.16 per
  row. The allowance is conservative, which is the safe side.
- **Under quadrature**, a censored row's exact marginal lies between a
  positive constant and 1, so the excess of the uncensored rows is
  exact. The closed form above confirms it.
