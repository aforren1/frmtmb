text in three files and no code. The minors m1 to m7 do not block.

## Item 3a: fuzz seed 20379118

Cause (`dev/relrev069-fuzzdiag.R`, 0.3.26 BLAS and LAPACK, log
`fuzzdiag-ob26-r7.txt`): the first nlminb run ends at "false
convergence (8)", objective -49.1818324061, finite gradient,
`rejected_last` FALSE. `optimize_obj()` restarts from it; that nlminb
call raises "NA/NaN gradient evaluation"; `optimizer_from_best()`
restarts from `last.par.best`, where the objective is now NaN (all 8
gradient entries non-finite), and the error propagates although the
first run's result was finite. Arms on the same build:

- `mo_search` is never entered (the error comes before it);
  `mo_search = FALSE` errors the same way.
- `nlminb_best_par()` replaced by the identity: errors the same way.
- the `mo()` chart put back to the softmax (`mo_simplex()` patched to
  `chart = "softmax"`, `mo_search = FALSE`): code 1, objective
  -34.0206625040, which is rellib-r6's result to the digit.
- the links are not involved (Gamma, log link).

So the trigger is optima's stereographic chart, which changes the path
on a REML likelihood that is unbounded (the reference build runs to

## Item 5: optima's c1

`summary_mo_frame()` marks `face <- w < mo_face_tol | w > 1 -
mo_face_tol`. A weight within `mo_face_tol` of 1 forces every other
weight below `mo_face_tol`, so the rule marks all weights of a simplex
at a vertex, consistent with `mo_search()`'s own trigger
(`min(w) < mo_face_tol`). `se`, and so the interval, are `NA` on those
rows; the `face` attribute is the row names after `sub("^simo_", "")`,
and `check_laplace()` re-prefixes `simo_`, which matches the draws'
column names for a sigma simplex too (`simo_sigma_...`). The empty
case is guarded (`if (length(face))` before `paste0()`). The release
tree's `R/methods-fit.R` and frmtmb.sample's `R/sample.R` equal the
lane's (no recon difference).

Seen to fail without c1 (`dev/relrev069-c1-before.R`, the face rule
put back to `w < mo_face_tol` in frmtmb's namespace and in
frmtmb.sample's imports): `test-optima.R` pass 97 fail 3 (all in "a
simplex at a vertex has no delta-method interval at 1"),
`test-mo-simplex-draws.R` pass 24 fail 3 (all in "check_laplace()
names a weight at 1 instead of judging it"), the lane's numbers. With
