## Verdict: FIX

The fix does what item 5115 asks: on the band data the default fit now
reaches the exact maximum (8 of 8 seeds, to 1e-6). Bitwise guard-absent
holds. Cost is small. But the new keep rule for a hole run accepts a
supremum at infinity: on separated bernoulli data the after build
returns a separated fit with code 0 and no warning on 9 of 10 seeds,
where 0.83.0 warned on 10 of 10. That is a new silent wrong result. A
second defect: from a fit with a distributional parameter at its limit
(student nu), the hole runs keep that parameter, and the kept fit is
16 to 44 below the maximum, presented by a message as the answer.

Fix items:

   Separated data (band data's x, y = 1 for x > 2, bernoulli,
   `a / (x + b)`), `nlband-review-sep.R`, seeds 1 to 10:

### 10. 5099 closure (check 6)

Sound as stated: `1 + exp(u) > 1`; `EC50^h + x^h` with x >= 0 and h a
coefficient is positive wherever defined (h < 0 included: EC50^h > 0,
x^h >= 0 or Inf at x = 0; EC50 < 0 with non-integer h is NaN). With x <
0 and h a coefficient the body is NaN off integer h, so no data the body
accepts break it. But the general case 5099 names (a denominator not
affine in one coefficient) has trapped fits the lane did not file
(`nlband-review-extra.R double`):

```
DBL a/(x + b)^2 seed 1   | before = after: default -708.787960 b 112.3715 msg - warn -   | from hole 36.622810 b -1.9990
DBL a * (x + b)^-2 seed 1| before -708.787960 silent; after 36.622810 b -1.9990 frmtmb_nl_pole_start
(seeds 2, 3: a/(x + b)^2 710.1 and 861.5 short, warned; a * (x + b)^-2 fixed after)
CUBIC Emax * x^3 / (EC50^3 + x^3), x in (-4, 4): default -489.126913 msg frmtmb_nl_restart warn - | from EC50 -2 39.900985 (both arms)
```

The same model spelled `a / (x + b)^2` is not read (the base is affine,
the square is not), and `a * (x + b)^-2` is: nl_denoms() takes the base
of a negative power but not of a positive power under `/`. A literal
odd power with x of both signs has walls at EC50 = -x_i, silent 529
short. File both (MEDIUM for the spelling; it is cheap and exact to read
the base of `(.)^k` under `/`).

### 11. Rounding decides whether walls are read at large |x|

30-level two-fold dilution (x to 5.4e5), `nlband-review-extra.R dilw`:
`nl_pole_walls()` reads the walls on seed 1 and returns NULL on seeds 2
and 3 (same on both arms). The affine test `max(abs(b - 2a + m)) > 1e-8
* sc` compares a rounding error of order |x| eps (5e5 x 1.1e-16 = 5.5e-11)
with 1e-8 x 2h = 2e-11. Pre-existing (0.83.0), harmless here (no pole),
but whether the escape runs is rounding's choice on such data. File
(LOW).
