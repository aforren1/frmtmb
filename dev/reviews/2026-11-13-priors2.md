# Review of lane priors2 (round of 2026-11-13, base ec8178d3)

Adversarial review. Lane tree `frmtmb-wt-priors2`, library
`wt-priors2-lib`, base `rellib-r21`. Scripts and outputs:
`dev/reviews/priors2-review-*` (each script header gives its command).
No git writes; no lane file edited.

## Verdict: FIX

Five FIX items (F1 to F5), three LOW items, and two points for the
user. The rename, the mixture-weights class, the step-start message and
the `cor`/`resp` refusal hold up.

## FIX items

### F1. The infinite-density refusal is not a proof (item 2)

`R/priors.R` `check_map_unbounded()` (about line 5236) and
`box_end_density()` (about 5179) refuse every box end where the prior's
density is infinite. The code comment and `?set_prior` say "the
likelihood is finite there". That is not always true.

Reproducer: `dev/reviews/priors2-review-unbounded.R lane`, output
`priors2-review-unbounded-lane.txt`. Data: seed 11, n = 80,
`x ~ U(0.5, 2)`, `y ~ Pois(1.5 x)`.

- Case A, `frm(y ~ 0 + x, family = poisson("identity"), prior =
  set_prior("gamma(0.5, 1)", class = "b", coef = "x", lb = 0))`.
  As `b -> 0`, the log likelihood falls like `sum(y) log b` and the
  prior rises like `-0.5 log b`, so the posterior goes to 0 at the
  bound. The log posterior by hand: -3476.09 at b = 1e-12, -120.55 at
  b = 1.5, -169.26 at b = 3. With `lb = 1e-10`, frm() converges, code 0,
  objective 120.129961301298, b = 1.383301902.
  - Expected: a fit at b = 1.3833.
  - Actual: "A prior whose density is infinite at a bound has no
    maximum: x (gamma(0.5, 1), lb = 0)".
- Case B, the same with `beta(0.5, 2)`, `lb = 0`, `ub = 1` on
  `y2 ~ Pois(0.6 x)`: refused. With `lb = 1e-10`, the maximum is at
  0.6478533564.

The correct condition: the posterior has no maximum only where the
log likelihood stays bounded below as the parameter approaches the end
(for some value of the other parameters). The prior alone cannot
decide it. Recommended: treat an infinite-density end as open, like a
zero-density end. Then refuse only after the fit, if the open-chart
fit runs to the end (u to -Inf, or the data part of the objective
finite at the end while the prior part diverges). A pre-fit refusal
that evaluates the data part of the objective at the end is a proof
only where that value is finite.

Case C (gaussian slope, likelihood finite at 0) is a correct refusal.
On 0.82.0 that fit returned the interior local mode (code 0, objective
29.5619832612, slope 0.3022615629; `priors2-review-unbounded-base.txt`).
It did not stop at -Inf, as the NEWS bullet says (see F4).

### F2. Interior fits behind a zero-density end move by more than 1e-6 (item 1)

The brief's acceptance is "fits with explicit bounds and an interior
MAP must keep their optimum within 1e-6". The lane's own survey
(`dev/priors2-out/survey-cmp.txt`) shows `b_gamma2_in` 1.34e-6,
`b_beta_in` 2.1e-6 and `b_invgamma_in` 7.59e-6. `b_beta_in` was exact
against the tight optimum on 0.82.0 (0 off) and is 2.1e-6 off on the
lane (`survey-tight.txt`).

The path that moves these fits is the open chart itself:
`open_end_coords()` plus `open_end_finish()`. No other code path moves
a fit. `priors2-review-bitwise.R` ran 15 fits on both builds (gaussian,
glmm, poisson glmm, negbinomial, 2- and 3-component mixtures, ordinal,
nonlinear with priors, sigma ~ z, ar, b/sd priors, sigma lb/ub through
the log link, sd ub, a b box, and a mixture refit with
`default_prior(fit)`). All 15 lines are bitwise identical to 0.82.0:
objective, logLik and every outer parameter in hex
(`priors2-review-bitwise-{lane1,base1}.tsv`, `cmp` identical).

Fix: run the closed box first, as 0.82.0 does. Switch to the open chart
only when that run stops on an open end (par at the end, or the
objective not finite there). The four interior fits then stay
bitwise those of 0.82.0, and the three pushed fits still reach their
mode. This also merges better with famend (see item 8). Otherwise the
user must accept the 1e-6 breach.

### F3. `bound_inside()` can leave a bound outside (item 5)

`R/priors.R` `bound_inside()` (about line 5912) walks at most 64 steps
of one ulp of `b`. Where the inverse link is flat in ulps of `b`, one ulp
of `v` needs many ulps of `b`, and 64 steps do not reach inside. The
loop always ends (64 iterations, about 0.01 to 0.05 ms per bound), but
then it returns the original `b` without a message.

Reproducer: `dev/reviews/priors2-review-ulp.R`, output
`priors2-review-ulp.txt`. Logit ends `1 - 10^-seq(2, 5, 0.01)` (301
ends): lb stays outside on 29, ub on 32 (for example ub = 0.99981802991413904).
Log 0.90 to 1.10, log 0.05 to 5, sd scale, logit 0.01 to 0.99, probit
and cloglog 0.01 to 0.99: 0 outside.

- Expected, per `?set_prior` ("moved inside by the few ulps the
  link's rounding needs"): `linkinv(bound)` inside every time.
- Actual: outside on 61 of 602 ends.

Fix: double the step on each iteration (64 doublings cover any gap),
optionally followed by a bisection back toward `b`. Add these ends to
`test-prior-bounds-ends.R`.

## LOW items

- L1. An old covariance spelling that has no density gets no pointer
  to `thetacov` (`priors2-review-theta.txt`).
  `set_prior("", class = "theta", coef = "theta_4", lb = -1, ub = 1)`,
  the exact form of the old `?set_prior` example, is refused with
  "class = "theta" takes no lb/ub: a simplex is bounded by its own
  constraint". Without lb/ub it is refused with "theta_theta_4 ~ ."
  (the prior string is empty). Add the `thetacov` hint that the
  non-dirichlet refusal already has, at least where `coef` matches
  `^theta(ac|r)?_[0-9]+$`. No old spelling is silently routed to the
  weights: every one with a density or a bound is refused.
  `frm(prior = set_prior("", class = "theta"))` on a model with no
  mixture is accepted. That is frm()'s general rule for an empty row
  (`class = "b", coef = "zz"`, `"simo"` and `"thetacov"` are accepted
  the same way, `priors2-review-theta2.txt`), and it is a no-op, not a
  dropped density.
- L2. The F1 refusal tells the user to "sample the posterior with
  frmtmb.sample's frm_sample()". `frm_sample()` refuses the same
  coef-level bound ("Prior argument 'coef' may not be specified when
  using boundaries"). With the bound written class-wide, it samples
  case C: 150 draws, b_z mean 0.3009 (`priors2-review-sample.txt`).
  Say so in the message.
- L3. Callers that build their own box drop the open flags:
  `quad_settle()` trust-region rounds (fit.R about 2386),
  `quadrature-nested.R:875` and `mo_search()` (fit.R about 4917). Each
  starts from a converged interior point, so this is not a regression
  against 0.82.0. Note it in the `open_end_flags()` doc.

## Items that pass

- Item 1, the rename: every class reader in core R, the extensions,
  tests and vignettes uses `thetacov`, except F5. The live dev drivers
  name no class.
- Item 3: class `theta` with a density on a non-mixture model, on a
  mixture with `theta1 ~ x`, without `resp` in a multivariate model,
  with `resp` on a univariate model and with `resp` naming a
  non-mixture response is refused through `validate_prior()` and
  `frm()`. The wording "has no mixture()" is slightly off for the last
  case, where the model has a mixture in another response.
- Item 4: at four points on the log-ratio chart of a 3-component
  mixture under `dirichlet(c(3, 1, 2))`, three densities agree: frm()'s
  prior, the hand formula `lgamma(sum a) - sum lgamma(a) +
  sum a log w` with `w = softmax(c(z, 0))`, and frmtmb.sample's tape.
  frm() against the hand formula: max difference 1.8e-15. Sampler
  minus frm(): 0 at all four points. `mix_theta_nlp()` steps aside.
  `dirichlet(c(200, 1, 1))` moves the weights from 0.446, 0.336, 0.219
  (ML) to 0.934, 0.042, 0.024. The rows: fit route `(flat) theta`,
  sample route `dirichlet(1) theta` (brms: `dirichlet(1) theta` for 2
  and 3 components), multivariate one row per mixture response (brms:
  `theta|y`), none with `theta1 ~ x`. `frm(prior =
  default_prior(fit))` is bitwise the ML fit. Default mixture fits are
  bitwise those of 0.82.0 (F2's 15 cases).
- Item 6: after the open chart, the reported fit is the final run in

  `lb = 1e-8` fit to 1e-6 relative on all four densities and on a glmm
  (`priors2-review-se.txt`). There are no warnings. A closed upper end
  beside an open lower one, a binding upper end, a class-wide bound on

  the `lb = 1e-8` answer (`priors2-review-chart-lane.txt`). 0.82.0

## For the user

1. F2: accept the 1e-6 breach of the open chart, or take the
   box-first design (recommended; it also settles the famend overlap).
2. The class `theta` density on frm() carries the softmax Jacobian, so
   `dirichlet(1)`, brms's default, pulls the weights toward equal values
   on the MAP route. brms's optimizing default has no Jacobian. The lane
   chose this for consistency with `simo` and the sampler (its decision
   1); the reviewer has no objection.
