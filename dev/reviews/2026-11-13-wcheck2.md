## FIX items

### F1. The pair rule costs O(L^2 n) on every model with `(1 | obs)` and `sigma ~ fac`, weighted or not

`R/weights-unbounded.R:349-369`, `unbounded_cell_pair()`: the double
loop over units calls `intersect()` on row sets and `excess_of()` (two
more `intersect()` calls) for every ordered pair. The loop runs on
each model that reaches the cell rule: a spike family, an
observation-level effect in mu and a dispersion design with indicator
columns. Weights are not necessary: an unweighted model has all excess
0, so the loop cannot refuse, but it still runs completely.

`Rscript dev/reviews/wcheck2-review-time2.R <base|lane>` (unweighted,
`y ~ x + (1 | obs)`, `sigma ~ 1 + fac`, seed 3; log
`time2-<arm>.txt`):

| n, levels | check, rellib-r21 | check, lane | whole frm(), rellib-r21 | whole frm(), lane |
|---|---|---|---|---|
| 1000, 50 | 0.01 s | 0.56 s | 1.86 s | 2.91 s |
| 2000, 100 | 0.04 s | 3.00 s | 1.58 s | 3.55 s |
| 4000, 200 | 0.16 s | 13.75 s | 5.14 s | 17.65 s |

Weighted (`w` 0.95, `wcheck2-review-prior.R time`, log
`prior-time-<arm>.txt`): n 6000 with 300 levels takes 0.80 s on
rellib-r21 and 48.07 s on the lane. I stopped the lane's n 10000 with
1000 levels run. Extrapolation gives about 15 minutes per call.

Expected: no measurable cost when no pair can refuse, and O(n + L^2)
scalar work otherwise. Fix: compute each unit's `gain` (E/n) and
`loss` (W/n) once, from one pass over the rows (`rowsum()` or
`tapply()`). Return NULL at once when `max(gain) <= min(loss)`
(always true without weights). Test disjointness with a logical
membership matrix or, for the disjoint-cells case, by construction.
Do not compute `intersect()` in the loop. Add a timing guard to the
test file in the form the round accepts (a ratio to a measured
reference, not an absolute time).

### F2. "The best direction is a pair" holds only for treatment columns of one factor with every column free

The roxygen of `unbounded_cell_pair()` (`R/weights-unbounded.R:286-288`)
says "Other directions add nothing: with `Ic` held, the best one is a
pair". The NEWS bullet says "The check refuses such a model when sigma
has the log link and each coefficient that moves has no prior, a flat
prior or a `student_t()` prior". The 4977 CLOSED line in the backlog
says "the linear program's optimum is a pair of cells". The code puts
only units that one column moves (plus the reference level, when the
cells are disjoint) into pairs. Thus the code does not detect a design
in which the shrinking and growing sets are not those units.

Independent check (`wcheck2-review-pair.R lane grid`, log
`pair-grid-lane.txt`): the asymptotic rate
`r(d) = sum_{s<0} (w-1)|s| - sum_{s>0} w s`, `s = X d`, with
`colMeans(X)'d = 0` and the held columns at 0, maximized as a linear
program (quadprog with a 1e-7 ridge, and a random search over
directions as a cross-check). There were 150 random weight
configurations per design, half of them with weights mixed in a cell:

| design | refused, LP > 0 | passed, LP <= 0 | false refusal | miss (LP > 0, passed) |
|---|---|---|---|---|
| 3 levels, treatment | 42 | 108 | 0 | 0 |
| 4 levels, sizes 10/20/30/40 | 77 | 73 | 0 | 0 |
| 3 levels + numeric z (free) | 47 | 103 | 0 | 0 |
| 3 levels, 9 rows at weight 0 | 48 | 102 | 0 | 0 |
| `f1 * f2` (2 x 2) | 0 | 77 | 0 | 73 |
| 3 levels, `contr.sum` | 0 | 101 | 0 | 49 |
| 3 levels, normal(0, 1) on `facb` | 0 | 143 | 0 | 7 |

The misses are real. Profiles of the Laplace objective along the
direction of the LP (`wcheck2-review-pair.R lane miss`, log
`pair-miss-lane.txt`) give slopes of exactly the LP's prediction:

| case | slope (predicted) | frm(), lane and rellib-r21 |
|---|---|---|
| `f1 * f2`, w 0.254 0.881 1.779 0.654 | 25.2 (25.2) | logLik 521.28, conv 1, warned |
| `contr.sum`, w a 0.226, b 0.914, c 1.783 | 25.1 (25.06) | logLik 742.669, conv 1, warned |
| same data, treatment contrasts | 25.1 (25.06) | refused |
| normal(0, 1) on `facb`, w 0.524 0.416 1.774 | 13.7 (13.68) | logLik 683.885, conv 1, warned |

Thus, one likelihood is refused or fitted to logLik 742.7 according to
the contrast coding of its factor. The misses are not silent (conv 1
with "false convergence" and a gradient warning), and rellib-r21 did
the same. But NEWS says such a model is refused, which is false.

Fix (minimum): make the three texts say what the code does ("cells
that one treatment column moves alone, or the reference level of a
factor whose cells do not overlap"). File the rest as an item. Fix
(recommended, small): when the dispersion design is saturated in its
row patterns (the distinct rows of the parametric X number `rank(X)`;
this holds for `contr.sum`, Helmert and full interactions), use the
patterns as units. Every pattern can then move alone with `Ic` held,
and the same pair test applies, with every column required to be
free. A held column is a real LP; leave it "unknown" and file it.

Neither direction produced a false refusal. Each refused case in the
grid has LP > 0. Near the boundary, 4 levels with a 1.12, d 0.1
(G +0.02) is refused, and the slope along the pair is 1.000 against
1.000 predicted. With a 1.08 (G -0.02) the fit passes, at logLik
-76.8355 and conv 0 (`pair-profile-lane.txt`).

### F3. The filed MEDIUM on asym_laplace understates the defect: its Laplace approximation has no maximum in sd for any grouped effect

The lane filed this: "asym_laplace's Laplace objective is not evaluated
at the inner modes" (MEDIUM). That statement is true, but the defect
is larger. The data give a row's own effect no curvature, so `H =
1/sd^2`. The Laplace term `-1/2 log H = log sd` then cancels the
normalizing constant of the effect's prior. With exact modes, the
approximation is `sum_g max_b [sum_i log f(y_i | b) - b^2 / (2 sd^2)]`,
which does not decrease in sd. Its supremum is at sd = infinity (and
for groups of 2, also sigma goes to 0). Thus, under the Laplace
approximation, asym_laplace has no estimate for any model with a
random effect in mu. Where frm() stops depends only on where TMB's
inner search fails.

`Rscript dev/reviews/wcheck2-review-al.R base <design>` (no weights,
no censoring, `y ~ x + (1 | g)`, seeds 20261114 to 20261123, logs
`al-<design>-base.txt`):

| design | fits | conv 0 | no warning | silent | exact-mode Laplace sup minus fit logLik, median (max) | max TMB mode error |
|---|---|---|---|---|---|---|
| 80 rows, groups of 4 | 10 | 0 | 0 | 0 | 6.63 (11.10) | 0.622 |
| 100 rows, groups of 10 | 10 | 0 | 0 | 0 | 2.90 (3.81) | 0.291 |
| 80 rows, groups of 2 | 10 | 0 | 0 | 0 | 49.24 (63.29) | 2.06 |
| 80 rows, groups of 4, ALD noise (p 0.3) | 10 | 0 | 0 | 0 | 5.35 (9.16) | 0.655 |

At each fit, the exact-mode Laplace rises monotonically along log sd
+0, +1, +2, +4, +8 (30 of 30 profiles, g10, g2 and al4; g4 ran
before the profile was added). One example, g10 seed 1: -136.6908,
-135.3548, -135.1741, -135.1463, -135.1458. The quadrature fit gave
no logLik in 8 of 10 g4 seeds, 5 of 10 g10, 4 of 10 g2 and 7 of 10
al4. In each logged case the error was "quadrature = TRUE could not
marginalize this model: the Gauss-Kronrod objective broke down". The
refusal text recommends `quadrature = TRUE`, so this matters.

Severity: the fits are not silent. All 30 end at conv 1 with
`frmtmb_conv_code` ("false convergence (8)") and
`frmtmb_conv_gradient`. But every asym_laplace or
zero_inflated_asym_laplace mixed model gives an sd and a logLik that
have no meaning. The warning tells of an optimizer problem, not a
model that has no maximum. I recommend HIGH, and that the next round
gets it by name: "asym_laplace Laplace with a random effect in mu has
no maximum". The likely fix is a refusal with a proof, with the same
form as the weights check's `laplace_linear` refusal of `(1 | obs)`,
gated by a free sd prior. The quadrature breakdown is a second item.
This is a user decision: severity, and whether to refuse asym_laplace
under Laplace with random effects in mu. Fix to this lane: rewrite the
filed MEDIUM with the statement above and these numbers (or file it as
a separate item), and put the severity question in the findings.

Other non-smooth densities: huber with `(1 | g4)` (`al-huber4-base.txt`)
finds its inner modes (max inner gradient at TMB's modes 1.33e-15 to
6.09e-11), so this defect does not affect it. But 7 of 10 huber fits
end at "false convergence (8)", 2 of them with "Standard errors are
not available for 4 of 4 parameters". The logLik of 5 of the 10 fits
differs from a fresh object's value at `fit$opt$par` by 0.064 to 0.136.
I did not diagnose this. I suggest that it be filed as LOW for
follow-up. The difference is therefore not evidence of warm-start
dependence for asym_laplace either: the evidence for asym_laplace is
the mode error column above.

### 4949 (attack 3)

The lane's argument that the censored rows cost 1/2 each under the
Laplace approximation with exact modes is sound. But see F3: the
exact-mode Laplace approximation of asym_laplace is not a quantity
that has a maximum, so "the check reads the Laplace approximation,
which has its maximum" is not true for grouped effects. Under
`(1 | obs)` with censoring, the lane's own "both" profile was noisy.
This does not change the weights check, which fails open there.
