## Blocking

**B1. `check_nl_sum_identified()` refuses identified models whose body
calls `pnorm()` or `dnorm()` with more than one argument.** The guard
treats `identical(stats::D(body, p1), stats::D(body, p2))` as a proof
that the body reads `p1` and `p2` only through their sum (`R/fit.R`
line 2559). That proof is false: R's `D()` differentiates `pnorm()` and
`dnorm()` in their FIRST argument only and returns `0` for a parameter
in the mean or sd slot, without an error (`dev/fixes-rev-D.R`,
`dev/fixes-rev-log/D.txt`):

    pnorm(pt, m2, s)                      D_m2: 0
    pnorm(pt, m1, s) + pnorm(pt, m2, s)   D_m1: 0  D_m2: 0
    dnorm(x, a, s) + dnorm(x, b, s)       D_a: 0   D_b: 0
    psigamma(a, b)                        D_b: 0

So two such parameters have "identical" derivatives (`0`), and with
intercept-only formulas their joint design `[1 1]` has rank 1, so the
guard refuses. Measured with `dev/fixes-rev-nl-false.R` on both builds
(`dev/fixes-rev-log/nl-false-{lane,base}.txt`), no priors:

| model | rellib-r5 | lane |
|---|---|---|
| the response-preparation model of `test-nl-rtmb-scope.R` (`pnorm(pt, m1, exp(ls))`, `m1, m2, ls ~ 1`), start given | conv 0, SEs 0.00889 0.00354 0.081 | REFUSED ("'m2' and 'ls' and 'm1' enter ... only through their sum") |
| psychometric `pnorm(x, m0, exp(ls))`, `m0, ls ~ 1` | conv 0, SEs 0.0454 0.059 | REFUSED |
| same model written `pnorm((x - m0) / exp(ls))` | conv 0, SEs 0.0454 0.059 | conv 0 (same) |
| Gaussian bump `h * dnorm(x, c0, exp(ls))` | conv 0, SEs 0.017 0.0116 0.0102 | REFUSED |

All three are identified (finite standard errors on the base build;
the first and third rewritten in first-argument form fit on the lane
build too). The test suite does not see this because the one suite
model of this shape, `test-nl-rtmb-scope.R` line 403, carries a prior
on every nonlinear parameter, which exempts it. The instrumented run
below shows it reached the guard with `same_D=TRUE` and passed only
through the prior exemption.

This is the case lane-rules.md names: a refusal that fires on a
correct model. Psychometric and signal-detection bodies written with
`pnorm(x, mean, sd)` are common in the cognitive-modeling material
this package targets.

Fix direction (for the worker to choose and measure): skip a pair
whose derivative is the constant `0` (it carries no information), and
skip any body holding a call to `pnorm`, `dnorm` or `psigamma` with more
than one argument, or replace the symbolic test by a numerical rank
test of the body's Jacobian in the coefficients at the data. Add the
three models above to `test-nl.R` as absent-case tests, seen to fail
on the current lane build. The NEWS bullet and the Rd sentence ("The
proof is symbolic and exact, so this cannot fire on an identified
model") must change with it.

### Blocking

**B2. `check_nl_identified()` refuses identified models in natural
units.**

- **Cause.** The three fixed points ignore the data's scale. Every
  coefficient sits at `0.15 + 0.35 * sin(.)`, so between -0.2 and 0.5.
- **Mechanism.** When a body saturates at all three points, one
  coefficient's Jacobian column stays nonzero and the others underflow
  to exactly 0. The null space is then the same coordinate subspace at
  all three points, and the guard refuses.
- **Evidence.** `dev/fixes-rev2-nl2.R`, logs
  `dev/fixes-rev2-log/nl2-*.txt`:

| Model | rellib-r5 | Lane |
|---|---|---|
| Logistic growth over calendar years, `Asym / (1 + exp((xmid - yr) / exp(lscal)))`, yr 1900 to 2000 | conv 0, est 49.352 1949.3 2.472 (exp = 11.85), SE 0.391 0.361 0.0239; nls SSlogis 49.3518 1949.3164 11.8465 | REFUSED: "xmid_Intercept, lscal_Intercept ... cannot all be estimated" |
| Psychometric with lapse, `lapse * 0.5 + (1 - lapse) * pnorm(x, m0, exp(ls))`, x 200 to 400 | conv 0, SE 0.0185 2.25 0.0947 | REFUSED: "m0_Intercept, ls_Intercept" |
| Emax with `exp(led50)`, dose 100 to 1000 | conv 0 | conv 0 |

These are textbook models in their usual units.

Two variants escape only by luck:

- With `scal` in place of `exp(lscal)`, `scal` turns negative at one
  point. The rows become non-finite and the guard fails open.
- Without the lapse term, every column is zero and the guard returns
  early. The same holds for the other natural-unit and small-n models
  in `dev/fixes-rev2-nl.R`: psychometric at x 50 to 150, decay at t
  1000 to 5000, Emax, and n = 4. All of them fit.

Fix direction:

- Treat a coefficient whose column is exactly zero at a point as
  "cannot judge", and fail open.
- Or place the points at the fit's own starting values (user `start`,
  prior location, `make_start()`) and perturb around them.
- Add both models above to `test-nl.R` as must-fit tests, and see
  them fail on the current lane build first.

**B3. The guard's cost grows as n squared and swamps the fit.**

- **Cause.** The guard tapes one output per row. `tape$jacobian()`
  takes one sweep per output, so the time is O(n x tape) = O(n^2).
- **Evidence.** `dev/fixes-rev2-nlcost2.R`, model
  `a * exp(b * x) + c0` with `a, b ~ 1 + z`,
  `dev/fixes-rev2-log/nlcost2.txt`:
