## FIX items

### F1 (HIGH). GEV cap 500: a nested-quadrature GEV fit reports logLik = Inf

`R/families-extreme.R:850, 862, 870` (`exp_neg_capped(..., 500)`).
`tests/testthat/test-families-extreme.R:288-293` ("importance and nested
quadrature fit a GEV off its support") fails under OpenBLAS 0.3.26 and
0.3.32 LAPACK: `is.finite(as.numeric(logLik(fq)))` is FALSE.

Reproducer: `dev/reviews/famend-review-gevquad.R <base|lane> 3 [cap]`
(the test's `sim(3, 0.5)`, `y ~ 1 + (1 | g) + (1 | h)`,
`quadrature = TRUE`):

| R | build | cap | code | objective |
|---|---|---|---|---|
| reference | base | 700 | 0 | 214.7792046 |
| reference | lane | 500 | 0 | 214.7792046 |
| OB 0.3.26 | base | 700 | 0 | 214.7801659 |
| OB 0.3.26 | lane | 500 | 0 | **-Inf** (logLik **Inf**) |
| OB 0.3.26 | lane, cap forced to 700 | 700 | 0 | 214.7801659 |
| OB 0.3.26 | base, cap forced to 500 | 500 | 0 | **-Inf** |

The cap alone decides it: the lane with 700 is base to every printed
digit, and base with 500 is the lane. Expected: a finite logLik (or a
refusal); actual: code 0, logLik `Inf`, with only the "did not settle"
and large-gradient warnings, so `logLik()`, `AIC()` and every comparison
read `Inf`. Likely mechanism (not measured): below w = -500 the capped
term has zero derivatives, so the inner curvature of a random effect
whose rows sit there can reach 0 and the log determinant `-Inf`; the cap
at 700 makes that region 200 e-folds narrower.

The lane's acceptance ran this file on reference BLAS only (124 pass)
because its OpenBLAS run was denied; this is the case that rule is for.
The NaN band of item 3067 needs a fix that does not widen the zero-
derivative region of the inside rows: for example keep 700 on the inside
arm and cut the outside rows' `h` off the parameters before
`exp_neg_capped()` (the `Inf * 0` comes from the clamp branch only).
Rerun this test under both OpenBLAS versions after the change.

### F2 (MEDIUM). `frechet_ridge_gain()` moves `last.par.best`

`R/families-extreme.R:474-476`: `f0 <- fit$obj$fn(p); f1 <-
fit$obj$fn(q); fit$obj$fn(p)`. TMB's `fn` sets `last.par.best` and
`value.best` whenever a value is below `value.best` (TMB 1.9.25
`MakeADFun`, both with and without random effects). On an edge fit
`f1 < f0`, so the best point becomes the probe `q`. The comment (line
~459) says "the fit's state is as it was"; it is not.

Reproducer: `dev/reviews/famend-review-frechet.R` (log `frechet.txt`;
arm "off" replaces the check by a no-op in the same process):

```text
9031 fixed check on : last.par.best (fixed) - opt$par: 3 0 -3 ; value.best - objective: -1.37e-08
9031 fixed check off: last.par.best (fixed) - opt$par: 0 0 0  ; value.best - objective: 0
9031 (1|g) check on : last.par.best - opt$par: 3 0 -3 0; identical vcov: FALSE (max |SE diff| 1.21e-08)
9031 weights        : the same, 3 0 -3
```

Interior fits (9001, 9039, censored) are bit-identical with and without
the check (the check returns before evaluating at nu - 1 > 1e-3). On the
edge fits the moved state is read by `sdr_outer_point()`
(R/se-check.R:304, used by `se_check()` after `fit_end_checks()` and by
the deferred `sdreport()` path), the profile start in R/confint.R:695
(`confint(method = "profile")` output is not `identical()` on and off,
equal to 7 printed digits), `mi_laplace_tk()`, `gp_position_info()`.
Fix: wrap the three evaluations in `obj_state_save()` /
`obj_state_restore()` (R/se-check.R:287, the pattern of
R/fit.R:5143). Expected after: `last.par.best`, `last.par` and
`value.best` identical with the check on and off on seed 9031, with and
without `(1 | g)`. Cost of the check: 0.01 to 0.03 s per fit (not an
issue).

### F3 (MEDIUM). The nb/nb2 test depends on one rounding

`tests/testthat/test-family-fitend.R:125-141` requires a limit or
boundary MESSAGE from both spellings. Under OB 0.3.26, x * (1 + 2e-15 *
9) (`dev/reviews/famend-review-nbpert.R`, `nbpert-ob026.txt`):

```text
k  9 nb: code 1 lim FALSE ll -555.2624608225 last 24.1914 | nb2: code 1 lim TRUE ll -555.2624611745 | rel 6.34e-10  <== FAILS
   W: Optimizer did not report convergence: false convergence (8). A Newton step from the stop would still gain 0.00567 ...
```

The negbinomial stop at shape 24.19 is on the same flat ridge (logLik
equal to 6e-10 relative) and gets the convergence warning instead of the
limit message. That is a valid ending of this fit, so the test must
accept it (limit message OR the convergence warning, and the logLik
agreement), per the round rule on rounding-decided branches. The
unperturbed data pass under both OpenBLAS versions, so CI may pass by
luck. The missing limit message on a code-1 stop on that ridge is
selimit2/boundfam territory: file it, do not fix it here.

### F4 (LOW). The message's advice fails as written

`R/families-extreme.R:792` and NEWS.md:18 say

### F5 (LOW). "at any xi" is not what was measured

NEWS.md (3067 bullet), `R/families-extreme.R:212`: base has the NaN
band at xi 0.06, 0.3, 1, 3 and 10 (80 of 6085 points each) but NOT at
xi 0.001 and 0.01 (0 of 6085) (`famend-review-gev.R`, `gev-base.txt`).

### F6 (LOW). Tests swallow every warning

`fe_conds()` in test-family-fitend.R muffles all warnings, and the
Frechet edge test (line 82), the cs() wall test (lines 119-122) and the
nb test never check what else was raised. The round rule is that no
warning escapes unchecked. Use `allow_warnings(..., allowed = )` for
those fits, or assert the list of warning classes.
