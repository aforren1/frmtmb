### (a) An estimated row called fixed: YES, one case

`ci082-short-attack.R <arm> oufar`: the review's `ouind` design with one
more time, `times = c(0, 0.5, 1, 2, 8, 20, 40, 1000)`, independent data,
seeds 1 to 3, no caller start, code 0. Each correlation is
`exp(-rate * D)` of the estimated rate (log rate 3.44, 1.31, 3.54).
For lag >= 960 the row is exactly 0 at the estimate, at the start (rate
1: `exp(-960)` underflows) and at both +/- 1 points, so every point
"agrees" and the row is called fixed.

| seed | 0.82.0 (`atk-base-oufar.txt`) | lane (`atk-lib-oufar.txt`) |
|---|---|---|
| 1 | 17 NA, 1 warning ("17 components") | 7 se 0, zero width; 10 NA, warning ("10 components") |
| 2 | 7 NA, 1 warning | 7 se 0, zero width [0, 0], NO warning |
| 3 | 18 NA, 1 warning | 7 se 0, zero width; 11 NA, warning |

The 7 rows per seed are exactly the pairs with `tim(1000)`. This is the
review's FIX 1 defect (an estimated, underflowed row: NA + warning to a
silent zero width) on a slightly wider time grid. It contradicts the
NEWS bullet ("Estimated components are unchanged") and the contract the
lane's own test pins (`test-covstruct-seam.R:193`,
`all(is.na(se[co$estimate[cr] == 0]))`), which would fail on these data.
`exp()`, `gau()`, `mat()` have the same `exp(-D / l)` form.

Fix (minimal, deterministic): never call a row fixed whose value at `t0`
is exactly 0, `fixed <- is.finite(g0) & g0 != 0` at `:990`. Such a row
keeps 0.82.0's NA + warning; for an underflowed row its jacobian row is
exactly 0, so that is not rounding's choice. Cost: a registered structure
that fixes a correlation at exactly 0 also keeps 0.82.0's NA + warning
(deterministic, not a flip). Add the far-time `ou` fit to the new test.
Alternative: probe only registered (non-core) structures; no core
structure fixes a reported row, but extension structures would still
reach the underflow.

`ci082-short-invprobe.R` (no fit; a registered structure whose vcov is

fixes (the review's option (b)). Not a blocker; record it.

Also deterministic, not a flip: a registered structure that fixes its

### (3) The log-sd exception

An estimated log sd that reads exactly 0 (sd exactly 1) at `t0`, at
`start(bk)` and at every +/- 1 point needs the sd to be insensitive to
its parameter over that whole set. Underflow cannot do it: an sd that
underflows gives `log(0) = -Inf`, not finite, so a move. Absorption can,
but only with a start inside the absorbed region, and then the value 0
plays no role. Part B: a registered structure with sd
`sqrt(c + exp(2 theta))` at `theta = -30` (`exp(-60)` absorbed):

| c | log sd at t0 | default start (0) | start -30 |
|---|---|---|---|
| 1 | 0 exactly | not fixed | sd rows fixed |
| 4 | log 2 | not fixed | sd rows fixed |

So for sd rows the start probe decides; excluding 0 would change
nothing for an estimated row and would send a structure that fixes a
unit sd to the zero-se NA. The lane's choice is sound. The start-in-the-
flat-region case needs a registered structure with a non-default start
and a variance its parameter cannot move; record only.
