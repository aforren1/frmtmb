# Adversarial review: lane predread (round of 2026-10-29, base d5d0056d)

Under review: the uncommitted diff in `frmtmb-wt-predread`, installed in
`wt-predread-lib`. Before-build: `rellib-r16`. Every number below comes from a
`dev/review-predread-*` script in this worktree; logs are in
`dev/review-predread-out/` (gitignored). Each script names its seed in its
header.
"At fixed values" means a Fixed_param brmsfit at the `frm()` estimate
(`brms_fixed_fit()`) beside `frmtmb_draws` whose every draw is that estimate.

## Verdict

**FIX.** The `cs()` layers, the `dpar = "mu"` change, the shared builder, the
`resp` readers on the methods the lane names, and `update(prior = )` hold. The
`me()` analog on the response scale does not: seven MAJOR findings, all in the
readers of a new `me()` row. One of them, M5, becomes a hard error on every
`me()` fit once nlfix is merged. One decision is for the user (D1).

## Findings

### MAJOR

**M1. `fitted()` on a new `me()` row reads a conditional value as a mean.**
`dev/review-predread-mefam.R`, seed 7971, 4000 draws, at fixed values. Row `x =
1`:

| family | sdx | brms mean | `fitted()` | brms / frm |
|---|---|---|---|---|
| poisson | 0.3 / 0.8 / 1.2 | 3.06 / 3.55 / 4.53 | 2.99 | 1.03 / 1.19 / 1.52 |
| negbinomial | 0.3 / 0.8 / 1.2 | 3.06 / 3.73 / 4.78 | 2.99 | 1.02 / 1.25 / 1.60 |
| lognormal | 0.3 / 0.8 / 1.2 | 3.60 / 4.12 / 4.96 | 3.53 | 1.02 / 1.17 / 1.41 |
| hurdle_poisson | 0.3 / 0.8 / 1.2 | 2.09 / 2.56 / 3.53 | 2.00 | 1.04 / 1.28 / 1.76 |
| zero_inflated_poisson | 0.3 / 0.8 / 1.2 | 2.21 / 2.59 / 3.52 | 2.15 | 1.03 / 1.20 / 1.63 |
| bernoulli | 0.3 / 0.8 / 1.2 | 0.772 / 0.757 / 0.737 | 0.774 | 1.00 / 0.98 / 0.95 |
| cumulative, category 1 | 1.2 | 0.197 | 0.174 | 1.13 |

Against the truth (`dev/review-predread-sesim.R`, seeds 1 to 200, `b = 0.7`):
`E[y]` is 1.28 times `fitted()` at `sdx = 1`, which equals `exp((b sdx)^2 / 2)`.
This is latres's M6, and latres now uses Gauss-Hermite on new rows
(`latres_fitted_mean()`). The two must match: on the merged tree one model with
both terms integrates over the latent residual and not over the `me()` value
(section "Trial merge", S4). NEWS and `R/compat.R` say the estimate is "the mean
of the draw". That is true of `x` and false of the response.
Fix: integrate per row at `s^2 = sum (g sdx)^2`, through the seam latres built,
on
the response scale. `frm_linpred(type = "link")` stays the plug-in, as it is
exact
there.

**M2. `fitted()`'s interval leaves the support.** Same script and table.
`fitted()` builds `Q2.5` and `Q97.5` as `Estimate +- 1.96 Est.Error` on the
response
scale. A coefficient standard error was small enough to hide that. This variance
is not:

| family, sdx 1.2 | `fitted()` interval | brms quantiles |
|---|---|---|
| poisson | -2.26, 8.24 | 0.50, 17.75 |
| negbinomial | -2.73, 8.70 | 0.43, 20.96 |
| gamma | -1.96, 7.98 | 0.58, 15.54 |
| beta | 0.441, 1.051 | 0.371, 0.937 |
| bernoulli | 0.439, 1.109 | 0.339, 0.958 |

In the simulation at `sdx = 1` the lower end is negative on 200 of 200 seeds,
and
the interval covers the true mean at the drawn latent on 88 and 91 percent of
them
(nominal 95). `conditional_effects()` on the same fit gives 0.515, 17.33 for

shows
`emmeans(epred = TRUE)` with the symmetric SE, 2.99 with SE 1.79 against brms's
HPD
0.67, 7.98. Fix: map the link-scale interval through the inverse link, as
`conditional_effects()` does.

not
read the latent.** `dev/review-predread-regress-me.R`, seed 7402,

### For the user

**D1. One `me()` term read by two responses or dpars. I recommend sharing the
latent, as
a stated divergence, and the fix is not one line.**
`dev/review-predread-mejoint.R`, seed
7701, `y1 ~ me(xo, sx)`, `y2 ~ me(xo, sx)`, slopes 1.49 and 1.19, sigmas 0.39.
Reproduced:
brms's draws give `cor(y1, y2)` 0.007, 0.003, -0.015 by row, as the lane says.
Why brms is
clearly wrong here:

- Its Stan program has one `Xme_1`, read by both `mu_y1` and `mu_y2` (printed in
  the log).
  brms's own draws on new data contradict the model it fitted.
- brms disagrees with itself. With `save_pars(latent = TRUE)`, the correlation
  of the two
  expected values over draws is 0.99, 0.98, 0.97, 0.98, 0.99 on the first five
  rows in
  sample, and 0.006, 0.001, -0.024, 0.007, 0.031 on the same rows as `newdata`,
  same fit.
- The check against data. At the training rows, the observed correlation of
  `y - E[y | x_obs]` is **0.734**. Theory for one shared latent is **0.7385**.
  brms's
  replicates give **-0.001**. Any predictive check of the joint fails under
  independence.

| row sdx 0.5 / 1 / 2 | independent (brms) | shared |
|---|---|---|
| predictive `cor(y1, y2)` | 0.007 0.003 -0.015 | 0.739 0.918 0.978 |
| `var(y1 + y2)` | 1.22 3.88 14.3 | 2.10 7.47 28.9 |
| `var(y1 - y2)` | 1.20 3.86 14.7 | 0.33 0.40 0.66 |
| 95 percent width of `y1 - y2` at sdx 2 | 15.08 | 3.18 |

The marginals agree either way, which is why the lane's audit cannot see this.
For a dpar,
`mu` and `sigma` reading one call: predictive skew 0.03, -0.02, -0.14
independent, and 0.33, 0.36,
0.63 shared (`dev/review-predread-share.R`), so a marginal does change there.

The lane's "one line" is false. Mutant `me_share` drops `resp` and `dpar` from
the key
(`dev/review-predread-share.R`):

| reader | `cor` by row | target |
|---|---|---|
| core `predict()` | 0.728 0.919 0.978 | 0.739 0.918 0.978 |
| `posterior_predict()` on draws | -0.019 0.009 -0.015 | same |
| `posterior_epred()` on draws | -0.025 0.017 -0.003 | 1 1 1 |

Draws evaluate each response through its own `draws_fit_at()`, so each gets its
own store.
Sharing needs one store per draw across the responses, and it flips the pin in
`test-me-newdata-brms.R` ("two responses draw independently", 3 assertions).
Recommendation: share, keep the NEWS line as a stated divergence, and file it

    me_node_value <- function(fit, loads, what) {
      # a list: z has one value per row, and an environment's name holds 10000
      # bytes, which about 500 rows pass. A fit reads a few hundred nodes at most
      memo <- list()
      function(z, d = 0) {
        for (m in memo) if (m$d == d && identical(m$z, z)) return(m$value)
        sh <- fit
        moved <- lapply(loads$by_key, function(g) g * z)
        moved[[loads$key]] <- moved[[loads$key]] + d
        sh[["eta_shift"]] <- list(by_key = moved)
        value <- what(sh)
        memo[[length(memo) + 1L]] <<- list(z = z, d = d, value = value)
        value
      }
    }

    prob_band_draw <- function(out, probs, mm, up) {
      q <- setdiff(seq_len(dim(out)[2L]), 1:2)
      # a middle category has a hump in the draw, and no interval about one point
      # reads that, so each row reads the draw's own quantile, on 99 points of
      # equal weight; the logit carries the coefficients' share of the variance
      vals <- lapply(stats::qnorm(stats::ppoints(99L)), mm$val)
      vr <- matrix(mm$var, dim(out)[1L], dim(out)[3L])
      for (k in seq_len(dim(out)[3L])) {
        V <- vapply(vals, function(v) as.matrix(v)[, k], numeric(dim(out)[1L]))
        V <- matrix(V, dim(out)[1L], length(vals))
        # each row is sorted once and read at its two ends, where quantile() sorts per end
        V <- matrix(t(apply(V, 1L, sort, na.last = TRUE)), nrow(V), ncol(V))
        m <- as.numeric(out[, 1L, k]) / up
        se <- as.numeric(out[, 2L, k]) / up
        v2 <- pmax(vr[, k] / up^2, .Machine$double.eps)
        infl <- sqrt(1 + pmax(se^2 - v2, 0) / v2)
        inside <- m > 0 & m < 1
        for (i in seq_along(q)) {
          h <- (ncol(V) - 1L) * probs[i] + 1
          v <- (V[, floor(h)] + (h - floor(h)) * (V[, ceiling(h)] - V[, floor(h)])) / up
          r <- stats::plogis(
            stats::qlogis(m) + (stats::qlogis(v) - stats::qlogis(m)) * infl)
          # a probability at 0 or 1 has no logit, and no spread either
          r[which(!inside)] <- m[which(!inside)]
          out[, q[i], k] <- r * up
        }
      }
      out
    }
