## Item 3, checked and holding

The gate (`gp_marginal_outer_gr()`):

- It is a valid bound on the 2-norm condition number of `V = V_f + diag(noise)`:
  `lambda_max <= trace(V_f) + max(noise)` because `V_f` is PSD, and
  `lambda_min >= min(noise)`.
- It is cheap: the diagonal of the dense `u x u` covariance it already builds.
- It reads the per-position noise `(sigma^2 / w + se^2) / n_j`, which is what the marginal
  factors.
- On 112 fits it reads 1.7 to 4.5 times the true condition number (true / bound 0.22 to 0.59,
  `se-near.tsv`), so it is tight enough to place the gate.

Near the gate, `dev/review-fitedge-se.R near`. The fits are 100 positions, `sin` and `2 sin(3x)
+ x`, plain, `z +`, `(1 | g)` and 2 replicates per position, 7 noises from 0.03 to 0.004, seeds
1 and 2, `set.seed(71000 + 13 seed + 7 i)`. Each fit ran with the route on and off, and the
Hessian was read three ways on one fit:

### 3. The `mi()` predictor and the refusal message

than the existing test. Without it nothing pins a model that both builds now fit.
