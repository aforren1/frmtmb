## How the release tree was built

The lanes were combined in `../frmtmb-wt-release` (branch
`wt-release` at `253b3ef7`, frmtmb 0.70.1), in the order dblbar,
famsimplex, famuni, postfix, optstart, illse, remeasure. Every lane is
on `d2ef6312` (0.70.0); 0.70.1 differs from it only by lane ci701's
commit (`R/confint.R`, `R/se-check.R`, two tests, NEWS, DESCRIPTION,
codemeta, `dev/test-backlog.md`). Nothing was committed and no git
write was made: blobs are read with `git show`, and `git merge-file`
works on files, not on the index.

- `dev/rel071-merge.sh` merges in one rerunnable pass, as
  `dev/rel070-merge.sh` did: it restores each of the 84 tracked files
  any of the seven lanes changed (without generated ones) to its HEAD
  (`253b3ef7`) blob, removes the untracked lane files an earlier run
  copied (`dev/rel071-log/copied-<lane>.lst`), merges the lanes in
  order with `git merge-file` against the `d2ef6312` blob (line endings
  normalized to LF), copies the lanes' untracked files again, then runs
  the consolidation's edits (`dev/rel071-resolve.R`) and the NEWS merge
  (`dev/rel071-news-merge.R`), and stops if a conflict marker is left.
  Illse is merged only with `bash dev/rel071-merge.sh illse`; without
  it, illse's files are still restored to HEAD, so the six-lane and
  seven-lane trees come from the same script. `man/*.Rd`, `NAMESPACE`,
  frmtmb.sample's generated `helper-brms-suite.R` and `R/links-brms.R`
  are left out of the merge: roxygen and `dev/famlink-gen-links.R`
  write them.
- Untracked lane files copied, 0 clashes (`dev/rel071-log/merge-2.txt`):
  56 from dblbar, 75 from famsimplex, 122 from famuni (2 generated Rd
  files skipped), 37 from postfix, 65 from optstart, 71 from remeasure.
  No lane left a trial-merge copy of the package in its tree. Logs and
  caches are gitignored and were not copied, except what a rerun reads
  as its reference: lane remeasure's `dev/remeasure-out/` (the r6, r7,
  r8 and v067 builds and the brms reference fits, 6 MB) and
  `dev/brmsport-bin2-log/`, and lane optstart's battery tables
  (`dev/optstart-log/battery/`), all into gitignored paths here.
- `dev/rel071-revorder.sh` merges every file two or more sources
  changed (17; ci701 in HEAD counts as one) in the reverse lane order
  and compares (`dev/rel071-log/revorder.txt`): 12 are identical; the
  other 5 differ by exactly the consolidation's edits (the four union
  conflicts below, which conflict in either order, and the count header
  of `test-simulate-density.R`). So no hunk of one lane depends on
  where another lane's landed.
- A second run of the merge left every file outside `dev/`
  byte-identical except the one file the resolve edited in between
  (`dev/rel071-snap.sh`, `dev/rel071-log/snap-a.txt`, `snap-b.txt`).
- The OpenBLAS builds of R were made in this tree with
  `dev/ciharden-openblas.sh 0.3.26 lapack` and `0.3.32 lapack`, from
  the release zips already on this machine (lane illse's download), so
  nothing was fetched (`dev/rel071-log/openblas-026.txt`, `-032.txt`).
- Interim builds go to `C:/Users/adf44/source/r/wt-release-lib`
