# The 0.66.0 round, 2026-09-29

The second parity round of 2026-09-29: six lanes of brms parity, then
their consolidation into frmtmb 0.66.0. This is the record of what was
done, how it was verified and what is left. Each lane's
`dev/<lane>-findings.md` has its validation, numbers and scripts, and
`dev/reviews/2026-09-29-<lane>.md` has its adversarial review.

## Lanes

Every lane worked in a git worktree off `1f40800d` (frmtmb 0.65.0). Main
gained one test commit, `56af5022`, before the consolidation.

## How the release tree was built

The six lanes were combined in `../frmtmb-wt-release` (branch
`wt-release` at `56af5022`), in the order sampfix, fams2, aterms2,
formula2, defects, postfit2. Nothing was committed there.

- The first five were applied with `git apply --3way` from each lane's
  uncommitted diff (the prior round's `apply-lane.sh`), excluding
  `man/*.Rd`, `NAMESPACE` and frmtmb.sample's generated
  `helper-brms-suite.R`. postfit2 was merged file by file with
  `git merge-file` against the lane's base blob, which touches no
  index, after a broad staging command was refused.
- Untracked files were copied without overwriting, 0 clashes, except
  lane sampfix's `dev/sampfix-rev-stan-cache/` (121 compiled programs,
  190 MB, a cache and not evidence) and the lanes' untracked generated
  Rd files, which roxygen writes.
- `roxygen2::roxygenise()` on core, install into
  `C:/Users/adf44/source/r/rellib-r4` (new; `rellib-r3` keeps the 0.65.0
  reference build), then each extension roxygenised against it and
  installed in dependency order. postfit2's three new Rd files needed a
  second roxygen pass, since their cross-references resolve only once
  every file exists; after that a further roxygenise of all eight
  packages changed none of the 204 generated files.
- `dev/stan-cache` was seeded from main and from the lanes' caches
  (content-addressed, so a union is safe). drmTMB 0.7.0 was installed
  from CRAN into `rellib-r4`: the first gated run skipped
  `test-drmtmb-agreement.R` (13) because `rellib-r3` had held it.

### Conflicts, and how each was resolved

1. `NEWS.md` and frmtmb.sample's `NEWS.md`, at every lane after the
   first: both sides kept, then regrouped by hand under one
   `# frmtmb 0.66.0` and one `# frmtmb.sample 0.14.0` heading with
   breaking changes first. Every lane's bullets are there once; lane
   defects' header paragraph went into the lead.
2. frmtmb.sample `R/methods-draws.R` (aterms2 against sampfix), in
   `posterior_epred()` and `posterior_linpred()`: aterms2's
   `subset_resp_check()` kept, with sampfix's layout-aware
   `draws_index(object)` in place of `draws_par_index(object$fit)`.
3. `vignettes/brms-migration.Rmd` (aterms2 against fams2): every bullet
   kept; the `cat()` sentence on the `thres()` bullet, then
   `hurdle_cumulative()`, `rate()`, `subset()`, and fams2's binomial
   bullet, which names `zero_inflated_beta_binomial()`.
4. frmtmb.sample `R/draws-brms.R` (formula2 against sampfix):
   `draws_natural_cols()` keeps sampfix's ordinal blocks and cache key
   and formula2's equated names in `extra`; `draws_to_natural()` drops
   equated columns on the inverse, then applies the ordinal map.
5. `tests/testthat/test-arg-refusal.R` (defects against aterms2): each
   lane removed a different row of the refusal list; both are gone,
   and the comment gives both reasons.
6. `R/conditional-effects.R` (postfit2 against fams2): fams2's
   category-code weights and `allow_new_levels` with postfit2's
   `ce_frame(surface = )`.
7. `R/sampling-api.R` (postfit2 against aterms2): both alias lists.
8. frmtmb.sample `R/conditional-effects-draws.R` (postfit2 against
   fams2): fams2's `ce_cat_mean()` code origin, then postfit2's
   spaghetti block.

Merged by hand as instructed: core's `tests/testthat/helper-brms-suite.R`
is lane defects' copy plus lane aterms2's two `brms_standata_view()`
hunks (`denom`, `idxl`), and nothing else, by `diff` against defects'
copy. frmtmb.sample's copy was never merged: `dev/brmsport-gen.R`
regenerated it, and `test-brms-suite-helper-copy.R` passes on it.

### Defects the merge created, found and fixed

- **sampfix's laplace probe in frmtmb.sample's `conditional_effects()`
  called `ce_draw_new_levels()`**, which postfit2 removed with three
  other exports; the hunks merged without a conflict. The probe now
  evaluates through postfit2's `ce_plan_eval()`, as the draw loop
  does. A grep for the four removed exports found no other caller.
- **frmtmb.sample's `pp_check()`**: defects' refusal of a `loo_*` type
  on an `mi()` model runs before sampfix's PSIS construction; both
  kept, and a comment that said bayesplot "otherwise died" was
  corrected, since sampfix builds the weights.

### Small fixes folded in

- formula2's `cmc = FALSE` refusal said "would leave one level out"
  for an ordered factor, whose contrasts are polynomial and leave no
  level out. It now names the columns of both codings, `(t1, t2, t3,
  t4)` against `(t.L, t.Q, t.C)` or `(t2, t3, t4)`, and says the
  contrasts are not coefficients of single levels. `?bf`'s `cmc` and
  the NEWS bullet say the same. Tested for both kinds of factor in
  `test-formula-cmc.R`.
- frmtmb.learn's `test-stan-identity.R` let 4 warnings escape, 2 per
  fit on 2 fits: "false convergence (8)" and the large-gradient
  warning. Both calls are wrapped in `allow_warnings()` naming those
  two messages; `helper-warnings.R` is now in frmtmb.learn's tests too.
  The scan of the file (`dev/warnleak-scan.R`, gated) went from 4 to 0,
  and the file passes 71 of 71.
- The scale tier found one more escaped warning: frmtmb.ode's
  `test-scale.R` fit ends with optimizer code 1 (`conv=1` in its row,
  as at 0.65.0, logLik -434.72 in both), which frmtmb reports as a
  warning, and `run-tests.R`'s new `warn=` count showed it
  (`warn=1`). The fit is wrapped in `allow_warnings()` naming
  "Optimizer did not report convergence", with `helper-warnings.R`
  added to frmtmb.ode's tests, and frmtmb.ode is bumped for it.
- `_pkgdown.yml` did not list postfit2's `conditional_smooths()`,
  `make_conditions()` and `update_adterms()`, so
  `pkgdown::check_pkgdown()` failed and the docs workflow would have
  stopped. They are listed now; the check passes for all eight
  packages.
- `dev/brms-api-diff.md` gains a note naming the rows this round made
  stale, which lane postfit2 left for the consolidation.
- `dev/lane-rules.md`: two rules, every extension suite that can reach
  a changed path, and a runner that attaches the package. The second
  was measured on the release build with `dev/rel066-noattach.R`
  (`dev/rel066-log/noattach.txt`).
- The release harness reads `rellib-r4`: `dev/release/run-tests.R`
  (which now also prints `warn=`), `run-check.ps1` (whose scratch moved
  from `C:/Users/adf44/source/r/checkout-r3` to
  `dev/release/checkout/`, ignored), `run-docs.ps1`,
  `dev/warnleak-scan.R`, and the defaults of `dev/brmsport-run.R` and
  `dev/brmsport-guards.R`. `dev/release/run-par.sh` is new: the same
  runner, one file per process, many processes at once.

## Left open

`dev/test-backlog.md`, "Filed at the 0.66.0 release", lists what each
lane found and did not fix, with its lane and measurement. In short:

- sampfix: a NaN the laplace watch can pass (R2); a harmless false
  alarm at `x = 0` (M2); covariance draws keep internal names; REML
  with `laplace = TRUE` samples the ML Laplace posterior; `?frm_sample`
  on named-list priors.
- fams2: `threshold = "equidistant"` and `"sum_to_zero"`; `disc` on the
  four older ordinal families; `thres(gr = )`, censoring and mixtures
  of the new families; the third derivatives in `log_pbeta_ad()`'s tie
  blend; upstream reports for brms and RTMB.
- aterms2: `conditional_effects()` with `mi(x, idx = )`; offset models
  in `conditional_effects()` and `emmeans()`; an addition term given an
  expression; `rate()` with censoring untested against brms; brms's
  global levels in a subsetted response, not built by choice.
- formula2: no default prior on a mixture's `sigma1` and `sigma2` in
  frmtmb.sample; a complete `bf()` in `update()`; the Formula line of
  `summary()`; `lf(disc ~ )` on `cumulative()`.
- defects: `predict(newdata = )` with NA responses under `cov = FALSE`
  ARMA; bernoulli recoding; `plot()` arguments that return ggplot
  objects in brms; `parnames()` on a fit; `nsamples(incl_warmup =)`.
- postfit2: new levels by brms's `"uncertainty"` rule; crossed and
  `mm(by =)` new levels on boot and draws; `pp_average()` and
  `model_weights()`.
